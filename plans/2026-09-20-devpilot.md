# DevPilot Implementation Plan

> **For agentic workers:** Execute with `superpowers:executing-plans`. The owner explicitly authorized autonomous implementation and architectural decisions without intermediate approval.

**Goal:** Build a secure, usable AI-native workspace that connects GitHub source to cited answers, specifications, implementation plans, tasks, reviews, and test suggestions.

**Architecture:** Next.js App Router serves React screens and same-origin authenticated API routes. PostgreSQL with Drizzle stores owner-scoped projects, source snapshots, pgvector chunks, conversations, artifacts, and tasks. A conspicuously labeled, isolated, ephemeral demo works without credentials; real GitHub/AI operations never silently fall back to sample output.

**Tech Stack:** Next.js 16, React 19, TypeScript strict, Tailwind CSS 4, PostgreSQL/pgvector, Drizzle, AI SDK, OpenAI provider for chat and embeddings, Zod, Node test runner, Playwright, CircleCI.

**Spec:** The owner's greenfield brief in this session, recorded in `docs/PROJECT_STATE.md`.

## Global constraints

- The empty-workspace blocker is RESOLVED. Git initialization and application creation are authorized.
- No repository code is executed. Repository paths, file sizes, total index size, request sizes, and provider timeouts are bounded.
- Authentication and project ownership are verified at every server boundary. Mutating browser requests require same-origin checks.
- Demo data is isolated per session, visibly labeled, bounded, and never confused with production data or live AI.
- Do not read real environment files or files with sensitive names. The explicitly authorized `.env.example` contains empty placeholders only.
- Do not deploy or push without authorization. Live integration checks that need credentials are individually blocked, not the whole project.
